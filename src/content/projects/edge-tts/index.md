Reverse-engineered the WebSocket-based Microsoft Edge Text-to-Speech service and published it as an NPM package.

Provides a programmatic interface to Microsoft's high-quality neural text-to-speech voices, originally designed for use with Edge browser.

Used as a core component in The Daily Algorithm project for automated voiceover generation.
