Automated content generation for TikTok and YouTube Shorts using **Google Gemini** for the script, my **Edge TTS** package for the voiceover, and **Remotion** for video rendering.

I intentionally over-engineered it to learn: microservices behind an API gateway, RabbitMQ, a React frontend, and Docker Compose for deployment.
