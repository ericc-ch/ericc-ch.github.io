Engineered a fully automated content pipeline for YouTube shorts using **Google Gemini** for script generation, custom **Edge TTS** implementation for voiceover synthesis, and **Remotion** for video rendering.

The system handles the entire content creation workflow from topic selection to final video generation with minimal human intervention.

Built with TypeScript and designed to produce consistent, engaging short-form educational content about algorithms and programming concepts.
