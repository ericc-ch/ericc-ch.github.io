Maintained fork of an unmaintained VSCode extension, adding syntax highlighting for tagged CSS template literals in JavaScript and TypeScript.

Published to Open VSX Registry for compatibility with VSCodium and other VSCode-compatible editors.

Provides essential developer experience improvements when working with CSS-in-JS solutions and lit-html templates.
